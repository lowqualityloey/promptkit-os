## 0. PromptKit OS Profile
- **Profile**: `balanced` (options: `lite` | `balanced` | `turbo` experimental)
- **Description**:
  - `lite`: 6 utility workflows (route, debug, commit, checkpoint, sync, profile) <1,500 tok, 80% value — onboarding
  - `balanced`: the full 24-workflow set, Level 0-3 adaptive ceremony (default) — teams, production
  - `turbo`: experimental, Balanced + parallel subagent waves, up to ~2x measured token cost, still requires human L3 approval
- **Upgrade Path**: Run `.promptkit/init.sh --balanced` for full, `--lite` for minimal, `--turbo --experimental` for parallel waves — or switch in-session with `pk:profile`

## 7. Non-Negotiable Architecture Rules & Guardrails
- [ ] **Locked workflow count (ADR 0002)**: 24 workflows. Additions require the ADR 0002 non-overlap gate; removals/retirements follow the same policy.
- [ ] **Token budgets (ADR 0001)**: Balanced directive ≤ 2,500 tok; Lite directive ≤ 1,500 tok. `measure-tokens.sh --strict` and `measure-per-task-tokens.sh --strict` must pass.
- [ ] **Zero-Lock-In**: Pure markdown protocols; no CLI binary, npm dependency, or daemon. No binaries or generated artifacts committed.
- [ ] **Bash/PowerShell twin parity**: Every validation/test script ships as `.sh` + `.ps1` with identical behavior; contract assertions updated in both twins in the same PR.
- [ ] **Atomic Conventional Commits**: One concern per commit; `feat:`/`fix:`/`docs:`/`test:`/`refactor:`/`perf:`/`chore:` per `workflows/commit.md`.
- [ ] **Absolute Secret Hygiene**: Never paste, expose, or request secrets, API keys, or credentials in chat. Run the local harness preflight (`scripts/check-harness-security.sh` / `.ps1`) before installer writes.
- [ ] **Bounded Oracle Gate**: No self-certified green — executed test/build command returning `exit code 0` required; max 2 auto-repair attempts before hard halt.
- [ ] **Reference Integrity**: `validate-references.sh` exits 0 — every internal link resolves.
- [ ] **Context Window Reset Threshold (~30 Turns)**: When conversation approaches ~30 turns or high token saturation, run `pk:checkpoint` to synchronize `docs/STATE.md` and recommend continuing in a fresh session via `pk:route`.
