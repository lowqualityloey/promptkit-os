# Isolation canary - ce-escalation-balanced
#
# The canary passes only when the read FAILS. The unisolated arm is the
# control: it must succeed, otherwise the canary proves nothing.
#
# The sweep is bounded and does NOT use -xdev. An earlier version ran
# `find / -xdev`, which cannot descend into a different device - and the
# bind-mounted fixture is a different device from /, so the canary could
# not see the fixture even when the file was plainly readable. It reported
# isolated=0 on every run, including runs where `cat` of the same file
# succeeded. Arm 3 below tests readability directly for that reason.
