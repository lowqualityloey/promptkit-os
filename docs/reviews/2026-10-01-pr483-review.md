## Findings

### R1 [P1] Preserve the referenced file's mode for internal symlinks

**Location:** init.sh:70–71, 864–866; profile equivalent:815–817.

An allowed AGENTS.md symlink pointing to a private 0600 file inside the project passes containment. The new mode helper queries the symlink itself: GNU stat without -L returns its mode, typically 777. The subsequent chmod follows the link and changes the private file to 0777. This introduces permission widening on successful installation. Resolve the physical destination consistently and query its mode with dereference semantics on both GNU and BSD, then preserve that mode. Cover internal file links, not just ordinary 0600 files.

The behavior follows the official [GNU stat documentation](https://www.gnu.org/s/coreutils/manual/html_node/stat-invocation.html) and [chmod documentation](https://www.gnu.org/software/coreutils/manual/html_node/chmod-invocation.html).

### R2 [P2] Canonicalize the leaf's parent in the Bash fallback

**Location:** init.sh:45–54, 64.

When realpath -m is unavailable or rejected, AGENTS.md -> ../outside/secret.md becomes the textual path /project/../outside/secret.md. Only directories receive physical normalization, so this ordinary file retains .. and passes the /project/ prefix check. The commit then follows the original symlink and modifies the external file. Resolve the leaf parent physically, normalize substituted link targets completely, and fail closed on unresolved paths. Exercise the fallback independently; Linux GNU realpath coverage does not establish portability. [FreeBSD realpath documentation](https://man.freebsd.org/cgi/man.cgi?query=realpath&sektion=1&format=html).

### R3 [P2] Resolve parents introduced by PowerShell link targets

**Location:** init.ps1:83–86.

Given AGENTS.md -> /project/relay/secret.md and relay -> /outside, Get-Item returns the final ordinary file with a lexical FullName beneath /project/relay. The resolver follows only reparse points on the returned leaf and never walks the relay component of the substituted target. Containment passes and WriteAllText changes /outside/secret.md. Resolve every component of link targets recursively with bounded, fail-closed resolution. [.NET FileSystemInfo source](https://github.com/dotnet/dotnet/blob/b0f34d51fccc69fd334253924abd8d6853fad7aa/src/runtime/src/libraries/System.Private.CoreLib/src/System/IO/FileSystemInfo.cs).

### R4 [P2] Use filesystem-appropriate case comparison

**Location:** init.ps1:114.

On a case-sensitive filesystem with root /tmp/project, an AGENTS.md link into the distinct /tmp/PROJECT directory is accepted by OrdinalIgnoreCase. The subsequent write changes an external file. Match the filesystem's case behavior when comparing canonical paths. This applies to pwsh on Unix; the Windows-only installer CI does not exercise it.

### R5 [P2] Snapshot each physical destination once before committing

**Location:** init.sh:517–520, 788–792; init.ps1:527–532, 900–904.

An existing .clinerules directory with promptkit.md registers that child twice: once from the directory candidate, once from its explicit child candidate. The second backup is captured after the first write, so it contains the upgraded directive. A subsequent write failure restores the original and then overwrites it with the upgraded second backup. PROMPTKIT.md restores the old profile, leaving a mismatched installation. Deduplicate canonical destinations and snapshot original state once. Alias spellings and internal links need the same treatment. Add a failure after writes begin; reversed-marker rejection only tests pre-validation.

### R6 [P2] Compose or reject profile/scaffold target overlaps

**Location:** init.ps1:639–642, 824–834, 886; init.sh:700–708, 816, 865.

With an installed Lite profile, --balanced --target=PROMPTKIT.md stages the custom target from the old Lite file. The profile commit first writes Balanced, then target commit overwrites it with the stale Lite profile plus Balanced directives. Installation reports success with an inconsistent profile. This regression follows from moving target snapshots before profile updates. Reject overlaps with managed profile/scaffold destinations, or combine both transformations into a single staged document.

### R7 [P2] Reject directory destinations before committing

**Location:** init.sh:868–869.

--target=docs with an existing docs directory is staged as a missing file because -f is false. cp succeeds by placing the staging basename inside docs (for example docs/target_0), and installation reports success despite not writing the requested file. The directory is also recorded as a created file, making rm -f fail during rollback. The base's append redirection rejected directory targets. Pre-validate that file destinations are absent or regular files before any mutation. [GNU copy destination semantics](https://www.gnu.org/software/coreutils/manual/html_node/Target-directory.html).

### R8 [P2] Preserve literal commas in native PowerShell targets

**Location:** init.ps1:162–163.

-Target "docs/AI,Rules.md" previously selected one literal filename. New splitting selects docs/AI and Rules.md instead, creating or updating unrelated files. Keep each native string-array element literal; arrays already express multiple targets. Preserve parity with the quoted Bash target.

### R9 [P2] Preserve trailing bytes during first Bash injection

**Location:** init.sh:701–708.

content=$(cat "$target") strips every trailing LF from an existing unmarked file. Rebuilding from that value loses original trailing blank lines: four trailing LFs become two before the directive. The base appended without rewriting the original bytes. Stage a byte-preserving copy, then append the separator and directive.
