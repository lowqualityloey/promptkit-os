## Axis 1: Spec Fidelity

### [P2] Make the dialog's reduced-motion override win against its state animations

Location: [templates/design-tokens-spec.md:318-319](https://github.com/lowqualityloey/promptkit-os/blob/8ba71e4781a419939accaf34d385ec2cf6a8d9d0/templates/design-tokens-spec.md#L318-L319).

The new motion-reduce:animate-none media utility has class specificity (0,1,0), while the existing data-state animation utilities add an attribute selector (0,2,0). The state utilities therefore retain the enter/exit animation name. The global reduced-motion rule changes animation duration to 0.01ms and iteration count to one; it does not disable the animation. This falls short of issue #466's explicit requirement that no transition or animation plays when this dialog renders with reduced motion enabled.

Gate the state animation classes with motion-safe, or use an effective important/state-specific animation override. This finding is based on the selector cascade and [Tailwind's documented data and media variants](https://tailwindcss.com/docs/hover-focus-and-other-states), not a rendered browser observation.

## Axis 2: Standards & Code Quality

### [P2] Keep the dark focus-ring token independently bright enough

Location: [templates/design-tokens-spec.md:94](https://github.com/lowqualityloey/promptkit-os/blob/8ba71e4781a419939accaf34d385ec2cf6a8d9d0/templates/design-tokens-spec.md#L94).

Changing dark --ring from #6366f1 to #4f46e5 reduces its contrast on the declared dark card/popover surface #0f172a from 3.996633:1 to 2.839356:1. On secondary/muted #1e293b, it falls from 3.274919:1 to 2.326625:1. When this token supplies the sole focus cue on these surfaces, it fails the 3:1 requirement for authored state indicators. It still passes against the root #020617 background at 3.208390:1, so a root-only check misses the regression. [W3C SC 1.4.11 guidance](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html#relationship-with-focus-visible).

Retain the brighter dark ring independently of the darker primary fill, or select and verify a replacement against all applicable surfaces. A separately contrasting focus cue can satisfy the requirement; the default token should not assume consumers provide one.
