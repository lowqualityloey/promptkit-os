## Public release notes

| Note | Impact | User-observable contract change | Evidence |
| :--- | :--- | :--- | :--- |
| N01 | minor | `PROMPTKIT.md` gains the optional `verify-surface: <path-or-none>` machine line. `verify-bootstrap` records it, and `pk:ship`, `pk:fix`, and `pk:review` prefer that done-gate target when present. The default `none` preserves the existing gate oracles. | `7ab8b50`, `workflows/verify-bootstrap.md`, `templates/project-profile-template.md` |
| N02 | minor | The turn-close contract is single-sourced as TL;DR opening, telemetry card, then callout. `api`, `auth`, `perf`, `research`, `reflect`, and `debug` now require the telemetry card at close when enabled, matching the workflows that already required it. | `7ab8b50`, `protocols/telemetry-cards.md`, the six workflow files |
| N03 | minor | CPAC scoring can now ingest a standardized telemetry record. New `extract-commandcode-telemetry` twins convert a Command Code session transcript into that record, and `measure-cpac` gains record scoring and pricing override flags. | `a45549a`, `d70332b`, `b9b2eb7`, `1d38ac9`, `39f7274`, `docs/BENCHMARK-METHODOLOGY.md` |
| N04 | patch | The npm courier tarball now includes the MIT LICENSE, fails fast with an actionable message on Node versions older than 18 or missing `fetch`, and its README now lists `--add-host=` and the full installer host set. | `8a26318`, `package/bin/promptkit-os.js`, `package/package.json`, `package/README.md` |
| N05 | patch | Installer kit-directory containment now checks a real path prefix, the attribution-hook path resolves without tilde expansion, and both hook installers tolerate CRLF removal and emit paths literally. | `1845506`, `54b65b3`, `48ffa1d`, `init.sh`, `init.ps1`, `scripts/install-attribution-hook.*` |
| N06 | patch | `workflows/pr.md` no longer tells maintainers to squash-merge an anchor-bearing PR, which would break the documented provenance-anchor ancestry requirement. | `3cd97fe`, `workflows/pr.md` |
| N07 | patch | `pk:doctor` documentation now matches the six-check engine contract already shipped in v2.0.1, including the sixth submodule-registration check and its CRLF parsing note. No new doctor behavior is introduced. | `7ab8b50`, `workflows/doctor.md`, `protocols/setup.md`, `templates/agent-directive-template.md` |
