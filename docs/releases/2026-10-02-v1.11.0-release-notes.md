## Highlights

- **Standardized Verification Evidence Contract**: A canonical machine-verifiable `evidence:verification` block that hosts, CI, and pre-commit harnesses can emit and that both execution-control validators now check mechanically.
- **Runtime Harness Positioning**: The 3-Layer Policy/Harness/Execution model and the Runtime Harness Adapter pattern make PromptKit OS's boundary against agent runtimes explicit.
- **Fail-Closed Validation Gates**: Five validators that previously passed when they should have failed now stop the line, and the npm courier verifies its tarball's SHA-256 before extracting or executing it — with the `1.10.1` pin minted, so existing installs verify too.
- **Interactive Installer Wizard**: `init.sh` / `init.ps1` gain a keyboard-driven wizard for profile, task-tracker, and AI-host selection with a final review step.

## Upgrade notes

No breaking changes. Existing Task Records with freeform verification text remain valid, and the `evidence:verification` block is validated only when present. Two validator behaviors intentionally tightened: a missing measurement input and an unavailable base ref on a pull request now fail instead of passing quietly.
