## Classification notes

- **Additive public contract (minor).** The two directive guardrail bullets and `protocols/context-sync.md` section 3.3 change what every installed agent is told to do, which is the same class of change the v1.7.0 evaluation classified as an additive public contract change. `docs/ENFORCEMENT.md` records the matching non-claim so the boundary is not read as enforcement.
- **Corrective public contract (patch).** The eight write-matcher commits correct a scoring harness that could report a recorded write of the guarded path as compliance; the README, FAQ, CONTRIBUTING, HOST-CONFORMANCE, ARCHITECTURE, and workflows/tasks commits correct statements that no longer matched the shipped installer or the measured figures.
- **Maintenance (none).** The v2.2.0 dossier, the `docs/BENCHMARKS.md` provenance-anchor restatements, the task record, the CHANGELOG entries, and the new injection rubric with its seeded fixture declare no intentional public contract change.
