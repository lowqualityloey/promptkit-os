## Bounded Intake & Planning Gate

**Greenfield discovery, bounded.** New `protocols/discovery-intake.md` with conditional `pk:onboard` Phase 0: size-classed (S/M/L) interviews covering MVP intent, surfaces, deployment, auth & data, constraints, and design inputs — asked in the context window (never modal pickers). Intake closes with a recorded `close_reason`; unanswered slots become owned assumptions; AI-suggested scope diverts to a **Later ledger**.

**Architecture gated on intake.** `pk:plan` Step 0 preflight plus the **MVP Floor**: every moving part traces to a user-stated requirement or lands in the Later ledger, with an accept-or-change defaults list. Modal pickers are bounded to closed-set choices. Mid-implementation deltas route through `pk:sync`/`pk:checkpoint` interception. Existing installs resolve to `legacy-partial` and are **never re-interviewed**.

## Telemetry Headroom & Status-Card Opt-Out

**Static budget with real runway.** The card format spec moved to lazy-loaded `protocols/telemetry-cards.md`: Balanced directive footprint drops 2,496 → 2,345 tok against the unchanged 2500 budget (Lite 1,079 of 1,500).

**Quiet completions available.** `status-cards: off` in `PROMPTKIT.md` suppresses the decorative card (default `on`); `> [!IMPORTANT]` / `> [!WARNING]` halts always fire.

## Measured, Not Asserted

**Behavioral eval harness.** 15 rubric scenarios score transcripts for observable compliance (Level declared, code withheld, halt callout fired) with an offline fixture self-test wired into both CI jobs. Baseline: 15/15 with 5/5 regression controls. The grep-based contract suite (108 assertions) now has a runtime complement.

**Proxy validated.** `bytes/4` checked against `tiktoken` (`cl100k_base`/`o200k_base`): gated directives match within 0–6%; workflow figures overstate 13–19%, so published payloads are conservative upper bounds. `bytes/4` remains the gate.

**LSP diagnostics, opt-in.** `pk:review` gains a read-only diagnostics pull on TypeScript repos (`LSP Enabled: true`), plus session-endurance rules, TL;DR-first output, and tracker-picker onboarding.

## Contributor Governance & Front Door

**Two-minute evaluation.** README halved to ~20k bytes with detail relocated to `docs/COMPARISONS.md` (hosts, competitors) and `docs/ARCHITECTURE.md` (operating model, command reference, layout).
