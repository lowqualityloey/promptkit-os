## Highlights (draft)

- **Breaking: Jev/System One assisted routing removed.** The router is now fully offline and deterministic; external-model recommendation output is gone.
- **Security: new npm couriers fail closed.** A valid SHA-256 archive pin is required before download; missing/invalid pins refuse without network, directory, extract, or install side effects.
- **Thirteen corrective fixes** across eval grading, checkpoint guards, synthetic-base detection, doctor coverage, router classification, and installer/tooling correctness.
- **Thirteen additive capabilities** including playbooks/stacks/recipes, handover identity, engine stamps, progressive compliance, handoff import, preflights, setup asserts, narrative scan, synthetic refusal, branch-namespace detection, doctor audit, the `pk` shim, and attribution policy.
