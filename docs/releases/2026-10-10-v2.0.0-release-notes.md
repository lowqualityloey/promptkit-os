#### Breaking change

Optional Jev/System One assisted routing is retired. `scripts/pk-route.{sh,ps1}` previously contacted an external evaluation endpoint with timeout fallback and external-model classification; the router is now fully offline and deterministic, with no network call, no external service, and no credential read. `--timeout/--dry-run` are accepted but ignored, timeout fallback and external-model classification are removed, and levels L0 through L3 are corrected from the assisted classifier. Migration is required and documented in `docs/MIGRATION.md` (PR #618), which covers key removal, timeout tuning, level re-validation, and the no-parity expectation; evaluation §7 remains the authoritative statement. The record carries coordinator content sufficiency accepted 2026-10-11 with independent QA attestation pending, and that coordinator acceptance is not independent reviewer attestation or release approval.
