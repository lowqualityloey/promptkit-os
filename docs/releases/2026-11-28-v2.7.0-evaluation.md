## Classification notes

- **Additive public contract change (minor).** The batch adds user-observable contract surface in three places and documents it in one commit. First, `pk:design` gains a resolved Surface Mode with utility-scoped aesthetic defaults and a single-owner delegation rule for an active external design skill, so a project can now state which visual register applies and which artifact owns `DESIGN.md`; the design profile gains a `Surface Mode` field and the token spec scopes its palette guardrail to the utility modes. Second, the telemetry-card contract gains a new default (`card-style: clean`) and two new opt-in styles (`gfm`, `framed`), a bullet-list compact status, and a conditional progress bar; `markdown` is retained as a deprecated alias rather than removed or redefined. Third, `pk:route` gains a consolidated single Turn-1 banner and an explicit precedence chain that names user-invoked external craft skills, and `pk:doctor` gains the STATE 3A to Task Record Current Actor mapping and copy-back remediation while keeping the `DIVERGED` token byte-identical. None of these requires a new credential, prerequisite, or manual consumer step.
- **Maintenance (none).** The v2.6.2 dossier prep and CHANGELOG cut (d7dae7c), the v2.6.2 independent QA review and approval record (6f7e6f7), the v2.6.2 publication outcome (7630727), the benchmark provenance anchor restatement (d47ae11), the renderer re-render test correction (6895aae), and this v2.7.0 dossier with its CHANGELOG cut.
- **No breaking change.** No removal, rename, or replacement of an existing contract occurs. The one visible default change (from framed to clean callouts) is an opt-out-able presentation default, and the prior meaning of `markdown` is preserved through the deprecated alias, so the additive classification stands and the minor candidate `2.7.0` follows.
