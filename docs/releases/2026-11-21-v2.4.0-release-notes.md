| N08 | patch | The dependency audit recipe's exception gate shipped with four fail-opens, each of which resolved "cannot judge" as "not a problem", plus a fifth defect that crashed the gate. ## Coverage and evidence

Every public note maps to exactly one entry in the CHANGELOG [2.4.0] section, in section order: N01-N06 to the six Added entries, N07-N10 to the four Fixed entries, and N11-N15 to the five Documentation entries. N01, N02, N04, and N05 are the additive changes and drive the minor candidate; every other public note is corrective. The v2.3.0 and v2.2.0 release records, the `docs/BENCHMARKS.md` provenance-anchor restatements, and the v2.4.0 dossier itself are maintenance because they do not alter the installed workflow, protocol, template, installer, courier, or measurement contract consumed by PromptKit OS users.

The four new documents are additive rather than repository-only documentation: a PromptKit install copies the kit tree into `.promptkit/`, so `docs/stacks/ai-app.md`, `docs/stacks/supply-chain.md`, `docs/recipes/llm-feature.md`, and `docs/recipes/dependency-audit.md` ship on every install, and shipped workflows already direct an agent to `docs/stacks/` and `docs/recipes/`. That is why N01, N02, N04, and N05 are classified minor rather than maintenance.

No breaking contract change is present, so no migration entry is required. The four new documents are additions to directories the shipped workflows already reference; the dependency-audit corrections change the recipe's own Pattern A code and its harness; the two workflow links add one line each; and the doctor, drift-table, awk, headline, FAQ, token-figure, and full-clone corrections restate existing behavior rather than changing it.
