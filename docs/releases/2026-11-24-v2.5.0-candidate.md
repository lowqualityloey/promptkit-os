- **Impact Precedence Rationale**: `The effective range contains one additive public contract group. Two new scripts ship inside the kit — `scripts/capture-host-session.mjs` with `.sh` and `.ps1` forwarders, and `scripts/render-capture-transcript.mjs` with `.sh` and `.ps1` forwarders — and each publishes a documented machine-readable output contract: `CAPTURE_PLAN|`, `CAPTURE_PROMPT|`, `CAPTURE_AGY|`, `CAPTURE_BWRAP|`, `CAPTURE_INVOCATION|`, `CAPTURE|<scenario>|<verdict>`, `CAPTURE_CANARY|`, `CAPTURE_BUNDLE|`, and the rendered transcript plus `observed-writes.log`. A PromptKit install copies the kit tree into `.promptkit/`, so both ship on every install, and `CONTRIBUTING.md` documents them as local gates. That is the same class of change the v2.2.0 evaluation classified as an additive public contract change and therefore minor: a new shipped script with a documented output contract is additive even when no shipped workflow names it. Six new live Context Economy evidence bundles under `docs/internal/host-conformance/antigravity/ce-*/` ship with them and are cited by `protocols/context-economy.md` section 11, so a shipped protocol gains a measured evidence table it did not have. The corrective set is large but patch-level: the `gemini` host now writes one directive instead of two (`init.sh`, `init.ps1`, `protocols/setup.md`, `scripts/check-doctor.sh`, `scripts/check-doctor.ps1`); the behavioral scorer grades the assistant text instead of the renderer; milestone-halt provenance accepts a host-neutral key pair; every bundle write log is tracked and a comment-only stub no longer grades as activity; the capture harness no longer ships its own answer key and its canary can now fail; the renderer no longer leaks the host time zone and no longer anchors on a file mtime; the Windows capture-test twin compares a normalized separator; the CHANGELOG gate rejects a repeated heading; and a pre-existing `GEMINI.md` is no longer refreshed. The v2.4.0 dossier amendments, the two task records, the Antigravity capture plan, and the `docs/BENCHMARKS.md` Turbo re-baseline are maintenance. Under the documented precedence major > minor > patch, the greatest effective impact is minor. No removal, rename, or contract replacement was found, so major is not justified.`
