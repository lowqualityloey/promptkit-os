## Public release notes

| Note | Impact | User-observable contract change | Evidence |
| :--- | :--- | :--- | :--- |
| N01 | patch | `--strip-directives` / `-StripDirectives` now compares file identity, in addition to the canonical path, before any protection decision, so a host file that is a hard link to `PROMPTKIT.md`, `docs/STATE.md` or any file inside `.promptkit/` - including a symlink that resolves onto such a hard link - exits 1 with zero mutations instead of having a PromptKit marker block stripped out of a user-owned file; two names for one inode are planned once, so a file is never stripped, backed up, or counted twice. `package/bin/promptkit-os.js` now re-checks `kitTargetKind()` immediately after the staged extraction, before the `--update` / `--force` / fresh-install replacement, so the refusal precedes the mutation. A non-git courier install re-run without `--engine-version=` (for example `./.promptkit/init.sh --solo-fast`, `--lite`, `--add-host`, `--reconfigure`, or a bare re-run) now resolves the engine identity from git metadata, an explicit flag, an existing validated `docs/STATE.md` stamp, or an existing managed host directive stamp, and only falls back to `unknown` when none yields a valid value, so a valid `v2.6.x` stamp is preserved instead of overwritten with `unknown @ unknown` / `Engine: unknown (unknown)`; every resolved value is validated against `^[A-Za-z0-9._+-]+$`. Both suites gain hard-link refusal and dedupe tests and a four-install engine-identity test. | `5bb7145`, `init.sh`, `init.ps1`, `package/bin/promptkit-os.js`, `scripts/tests/run-init-safety-tests.sh`, `scripts/tests/run-init-safety-tests.ps1`, `CHANGELOG.md`, `docs/tasks/TASK-2026-11-28-issue-818-819-strip-hard-links-and-engine-identity.md` |
