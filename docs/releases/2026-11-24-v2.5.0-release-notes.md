## Coverage and evidence

Every public note maps to exactly one entry in the CHANGELOG [2.5.0] section, in section order: N01-N07 to the seven Added entries, N08-N16 to the nine Fixed entries, and N17-N19 to the three Documentation entries. N01 and N03 are the additive changes and drive the minor candidate; every other public note is corrective. The v2.4.0 release records, the two task records, the capture plan, and the dossier itself are maintenance and carry no public note.

The two new scripts are additive rather than repository-only tooling: a PromptKit install copies the kit tree into `.promptkit/`, so `scripts/capture-host-session.mjs` and `scripts/render-capture-transcript.mjs` ship on every install, and `CONTRIBUTING.md` names both test suites as local gates. The six `ce-*` bundles ship with them and are cited by a shipped protocol, which is why N01 is a public note rather than maintenance.

No breaking contract change is present, so no migration entry is required. The `gemini` change is corrective rather than breaking: the host still receives exactly one directive, and an install that already carries a `GEMINI.md` keeps it untouched. Every other note corrects a shipped statement or a shipped behavior that no longer matched the measured or actual behavior.
