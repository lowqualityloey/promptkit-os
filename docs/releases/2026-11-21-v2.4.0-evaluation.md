## Classification notes

- **Additive public contract (minor).** The four new documents are not repository-only documentation. A PromptKit install copies the kit tree into `.promptkit/`, so `docs/stacks/ai-app.md`, `docs/stacks/supply-chain.md`, `docs/recipes/llm-feature.md`, and `docs/recipes/dependency-audit.md` ship on every install, and shipped workflows already point at `docs/stacks/` and `docs/recipes/` as the place to load a stack playbook or a boundary recipe. Adding four documents to a directory the shipped workflows direct an agent to read is the same class of change the v2.3.0 evaluation classified as an additive public contract change, and it is minor.
- **Corrective public contract (patch).** The dependency-audit gate corrections change code that ships inside a recipe the kit directs an agent to follow; the two workflow links change shipped workflow text; the drift-table and doctor corrections change what the kit reports about its own engine state; the awk correction changes whether the contract suite reports a correct tree as failing; and the headline, FAQ, token-figure, and full-clone corrections change what shipped documentation asserts. All are patch-level.
- **Maintenance (none).** The v2.3.0 and v2.2.0 release records, the `docs/BENCHMARKS.md` provenance-anchor restatements, and the CHANGELOG cut declare no intentional public contract change.
