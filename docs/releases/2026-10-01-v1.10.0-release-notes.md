## Upgrade and limitations

Existing valid profiles, project notes, and task records remain supported. New workflows are opt-in. Use the existing installation method to refresh the kit and rerun init.sh or init.ps1; inspect diagnostics instead of forcing unsafe destinations. For courier installs, replace the old kit using documented instructions. When updating copied environment snippets, replace the old createEnv helper: import clientEnv() from env.client.ts in client code and env from env.server.ts in server code; keep these modules separate. Live host compliance and independent cross-model success rates are unmeasured; this release makes no new live-fidelity guarantee. npm remains a delivery courier, not an application runtime.
