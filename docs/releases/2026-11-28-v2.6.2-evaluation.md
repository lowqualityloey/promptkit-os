## Classification notes

- **Corrective public contract (patch).** Issue #818 closes a fail-open path without expanding the user-observable contract: strip mode now decides protection from file identity, so a hard link - including a symlink that resolves onto one - to `PROMPTKIT.md`, `docs/STATE.md` or any file under `.promptkit/` is refused before any write, and the inode is planned once so a file is never stripped or backed up under two names. The courier moves its `kitTargetKind` re-check to immediately after staged extraction, keeping the refusal ahead of the replacement mutation. Issue #819 closes a second fail-open path: a non-git courier install re-run without `--engine-version=` no longer overwrites a valid engine stamp with `unknown`; it keeps the recorded identity and writes it back to `docs/STATE.md` and to managed host directives. Both suites gain regression coverage, and the change is documented in the CHANGELOG and the Level 2 Lite task record.
- **Maintenance (none).** v2.6.1 dossier prep, the v2.6.1 independent QA review and approval record, the v2.6.1 publication outcome, and this v2.6.2 dossier with the CHANGELOG cut.
- **No additive or breaking change.** No new capability, prerequisite, or required consumer action is introduced beyond refusing an install shape or a re-run degradation that a working consumer could not have depended on, so the effective impact stays patch and the patch candidate `2.6.2` follows.
