## Classification notes

- **Additive public contract (minor).** `scripts/capture-host-session.mjs` and `scripts/render-capture-transcript.mjs` are new shipped scripts, each with `.sh` and `.ps1` forwarders, and each publishes a documented machine-readable output contract that `CONTRIBUTING.md` names as a local gate. A PromptKit install copies the kit tree into `.promptkit/`, so both ship on every install. The six `ce-*` bundles ship with them and are cited by `protocols/context-economy.md` section 11, so a shipped protocol gains a measured evidence table it did not have. This is the class of change the v2.2.0 evaluation classified as additive and therefore minor.
- **Corrective public contract (patch).** The `gemini` host now writes one directive instead of two, which changes what every install of that host produces; the behavioral scorer grades the assistant text rather than the renderer; milestone-halt provenance accepts a host-neutral key pair; the bundle write logs are tracked and a stub no longer grades as activity; the capture harness no longer stages its own answer key and its canary can now fail; the renderer no longer leaks the host time zone or anchors on a file mtime; the Windows capture-test twin compares a normalized separator; the CHANGELOG gate rejects a repeated heading; and a pre-existing `GEMINI.md` is no longer refreshed. Each corrects a shipped statement or a shipped behavior that no longer matched the measured or actual behavior.
- **Maintenance (none).** The v2.4.0 dossier amendments, the two task records, the Antigravity capture plan, and the `docs/BENCHMARKS.md` Turbo re-baseline are repository history. They change no consumer contract and are recorded here so the range is complete rather than so they can be released.
