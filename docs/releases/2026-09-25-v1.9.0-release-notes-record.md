## What Shipped

**A courier, not a second implementation.** The `npx promptkit-os` package fetches the GitHub release tarball matching its own version, extracts it, and runs the canonical `init.sh` / `init.ps1`. All installation logic stayed where it was. The submodule path stayed canonical. Publishing is gated on version sync, a minimal-tarball assertion, the AC-1 courier/canonical equivalence smoke test, and provenance attestation.

**Governance that respects the human.** The Decision Card format plus Type A–D routing means discoverable answers get decided and reported instead of escalated, taste questions arrive as 2–3 options with a recommendation, and consequence-bearing decisions always reach the human. The session decision budget (3 Type B cards/questions, overflow to owned Assumption Records, Types C/D never capped) limits fatigue-driven delegation mistakes, not human authority.

**The carried backlog.** Stack playbooks, cross-cutting recipes, the skill coexistence contract, and sharpened verifier briefs shipped in the same set. They are certified in the companion evaluation rather than re-narrated here.
