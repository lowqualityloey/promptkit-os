| Note | Impact | User-observable contract change | Evidence |

| N01 | minor | `pk:design` resolves a Surface Mode (`Operate`, `Read`, `Persuade`, `Experience`) before applying aesthetics, so the matte paper, `1px` hairline, sub-`5%` accent and `system-ui` defaults apply as utility/operator defaults that an expressive brief may lift, while honest copy, WCAG 2.2 AA, responsive reflow, applicability-based interactive states and rendered-UI evidence never lift. `templates/design-profile-template.md` gains the `Surface Mode` field, the token spec scopes its palette guardrail to the utility modes, and `workflows/design-system.md` gains `External Design Skill Delegation`: an active external design skill is the single owner of visual direction, typography, palette and `DESIGN.md`, and PromptKit keeps the ceremony level, accessibility, reflow, state contracts and rendered-UI verification instead of forking a second token file. `docs/ADOPTION-GUIDE.md`'s Design System Skills row is updated in place. | `2c30de6`, `workflows/design-system.md`, `templates/design-profile-template.md`, `templates/design-tokens-spec.md`, `docs/ADOPTION-GUIDE.md` |
| N02 | minor | Routine status and halt callouts now default to `card-style: clean`, a borderless CommonMark form made of a `---` divider, a `>` blockquote, bold stop labels (`**🛑 ACTION REQUIRED — …**`, `**🚫 BLOCKED — …**`) and a bold `**👉 Reply:**` hint; the three-line compact status becomes a three-bullet list that cannot collapse. `card-style: gfm` (`> [!TYPE]`) and `card-style: framed` (CLI-only, open-right) are opt-in, `markdown` remains a deprecated alias of `gfm` so an existing install does not silently change meaning, and progress bars are conditional on a real countable list or `AC-*` checklist rather than a fabricated fraction. | `2c30de6`, `protocols/telemetry-cards.md`, `templates/agent-directive-template.md`, `templates/agent-directive-lite-template.md`, `scripts/tests/eval-scenarios/halt-callout.md`, `scripts/tests/eval-scenarios/halt-gfm-style.md` |
| N03 | minor | `Contract Impact Evidence or Maintenance Classification` in `pk:commit` is scoped to PromptKit OS repository commits only, so a consumer repository keeps Conventional Commits plus secret and probe hygiene. The Level 2 state rollover becomes a deterministic append-only recipe that moves whole contiguous blocks from `docs/STATE.md` to `docs/STATE-ARCHIVE.md`, keeps `pk:doctor` read-only, and adds no script to register or wire into CI. Both doctor scripts gain the `STATE 3A` to Task Record `Current Actor` mapping and copy-back remediation while the `DIVERGED(STATE 3A vs Task Record: <fields>)` token stays byte-identical. | `2c30de6`, `workflows/commit.md`, `workflows/checkpoint.md`, `workflows/route.md`, `scripts/check-doctor.sh`, `scripts/check-doctor.ps1` |

## Coverage and evidence

The three public notes map one-to-one onto the three entries in the CHANGELOG `[2.7.0]` section and carry additive `minor` impact, which drives the `2.7.0` minor candidate. Maintenance groups M01-M04 carry no CHANGELOG entry.

No consumer repository loses a supported install shape or owes a new manual step.
