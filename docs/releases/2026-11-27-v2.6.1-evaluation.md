## Classification notes

- **Corrective public contract (patch).** Issue #814 closes two fail-open paths without expanding the user-observable contract: strip mode now decides protection from the canonical identity of the target, so aliases and in-repo symlinks to `PROMPTKIT.md`, `docs/STATE.md` or `.promptkit/` are refused before any write, and the npm courier now fails closed on a `.promptkit` symlink (including dangling) or any non-directory object instead of writing through it. Both suites gain regression coverage, and `docs/ADOPTION-GUIDE.md` corrects the `--update` command and the Level 2 Lite default description.
- **Maintenance (none).** v2.6.0 dossier and publication-outcome records with the #813 post-release docs, the #814 task record and Windows-separator test correction, and this v2.6.1 dossier with the CHANGELOG cut.
- **No additive or breaking change.** No new capability, prerequisite, or required consumer action is introduced beyond refusing an install shape that a working consumer could not have depended on, so the effective impact stays patch and the patch candidate `2.6.1` follows.
