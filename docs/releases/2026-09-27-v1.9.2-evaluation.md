Root cause: the publish job passed registry-url to actions/setup-node, which writes a userconfig .npmrc containing //registry.npmjs.org/:_authToken=${NODE_AUTH_TOKEN}. The v1.9.1 tag and GitHub release are retained as an immutable record of the failed attempt and are NOT to be deleted or moved; the version number is burned and v1.9.2 supersedes it. No consumer-facing contract changed and no data was lost.`
- **Effective Change Set Summary**: `CI/DISTRIBUTION ONLY: .github/workflows/release-npm.yml drops the registry-url input from the Setup Node step, which removes the generated userconfig .npmrc auth entry that silently diverted the publish from npm trusted publishing (OIDC) to a token publish and caused the v1.9.1 E404.
