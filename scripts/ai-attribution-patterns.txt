# AI-attribution detector rules: RULE|regex|tier
#
# Loaded by scripts/check-ai-attribution.sh / .ps1 when PROMPTKIT.md declares
# `ai-attribution: off`. Each regex is applied line-by-line to a prepared commit
# message or PR/issue body. A missing or unreadable copy fails the check closed
# (exit 2), mirroring scripts/narrative-surface-rules.txt.
#
# Patterns target *unsolicited AI attribution* only: co-author trailers, or
# generated-by/generated-with footers that name an AI identity. They are
# deliberately NOT a blanket rejection of `Co-authored-by:` — a human co-author
# trailer does not match any row here and passes.
#
# Patterns are limited to syntax both POSIX ERE (grep -E) and .NET Regex support:
# no [[:space:]] classes, no `\s`, no alternation (a `|` would collide with this
# file's own field separator), and no non-ASCII. Trailer/footer rows are anchored
# to the start of a line so ordinary prose that merely discusses AI tools does
# not match.
#
# Extend or override per project with --rules-file, or append extra RULE|regex|tier
# files through PROMPTKIT_AI_ATTRIBUTION_RULES_EXTRA (whitespace-separated paths).
# Claude rows name the bot identity, not the personal name "Claude": the bare
# trailer form is followed by an angle-bracketed address, and the product form is
# spelled out. "Co-authored-by: Claude Martin <...>" matches neither and passes.
COAUTHORED_AI_CLAUDE|^[Cc]o-[Aa]uthored-[Bb]y:.*[Cc]laude[ ]*<|trailer
COAUTHORED_AI_CLAUDE_CODE|^[Cc]o-[Aa]uthored-[Bb]y:.*[Cc]laude [Cc]ode|trailer
COAUTHORED_AI_CODEX|^[Cc]o-[Aa]uthored-[Bb]y:.*[Cc]odex|trailer
COAUTHORED_AI_COPILOT|^[Cc]o-[Aa]uthored-[Bb]y:.*[Cc]opilot|trailer
COAUTHORED_AI_CURSOR|^[Cc]o-[Aa]uthored-[Bb]y:.*[Cc]ursor|trailer
COAUTHORED_AI_GPT|^[Cc]o-[Aa]uthored-[Bb]y:.*[Gg][Pp][Tt]|trailer
COAUTHORED_AI_ASSISTANT|^[Cc]o-[Aa]uthored-[Bb]y:.*[Aa][Ii] [Aa]ssistant|trailer
COAUTHORED_AI_SISYPHUS|^[Cc]o-[Aa]uthored-[Bb]y:.*[Ss]isyphus|trailer
GENERATED_WITH_CLAUDE|^Generated with .*[Cc]laude [Cc]ode|footer
GENERATED_WITH_COPILOT|^Generated with .*[Cc]opilot|footer
GENERATED_WITH_CURSOR|^Generated with .*[Cc]ursor|footer
GENERATED_BY_AI|^Generated by .*[Aa][Ii]|footer
ROBOT_GENERATED|^Generated with .*[Bb]ot|footer
